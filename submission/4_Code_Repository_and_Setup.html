2. Step-by-Step Local Setup & Execution

Step 1: Clone the GitHub Repository

git clone https://github.com/Sarthakadhav/Raasta-3D.git
cd Raasta-3D

Step 2: Install Project Dependencies

npm install

Step 3: Launch Local Development Server

npm run dev

The application will launch with hot module replacement (HMR) and can be accessed at:

http://localhost:5173

Step 4: Production Build & Preview

To compile the production distribution bundle and preview it locally:

npm run build
npm run preview

4. 100% Free Cloud Photogrammetry Pipeline (Google Colab)

Evaluators wishing to train a custom 3D Gaussian Splat from their own smartphone video can run our automated Colab notebook with zero setup:

  1. Open pipeline/Namma_Space_Raasta3D_Pipeline.ipynb in Google Colab.
  2. Select Runtime > Change runtime type > Hardware accelerator > T4 GPU (100% free).
  3. Upload your smartphone video (e.g., indoor_capture.mp4).
  4. Execute all cells sequentially:
    • ns-process-data video: Decodes frames and executes COLMAP Structure-from-Motion.
    • ns-train splatfacto: Optimizes 3D Gaussian Splats in ~13.8 minutes.
    • ns-export gaussian-splat: Generates the compressed .ply / .splat binary.
  5. Download the resulting .splat file and drag it directly into the Raasta-3D web viewer via the "Load Splat" button.
