Section 1: Technical Abstract & System Architecture

Technical Abstract
Traditional indoor spatial management relies on static 2D blueprints or disorienting 360° photo spheres that lack true metric depth and collision awareness. We present Raasta-3D: a 100% free, end-to-end intelligent spatial computing platform that turns casual smartphone video captures into photorealistic, interactive 3D digital twins.

Our architecture spans four sequential tiers: (1) a formalized monocular capture SOP, (2) automated Structure-from-Motion (COLMAP) and 3D Gaussian Splatting (3DGS splatfacto) running on free Google Colab cloud GPUs, (3) a semantic spatial indexing layer providing room-level POI tagging and optimal non-colliding A* indoor pathplanning, and (4) a zero-install WebGL viewer co-rendering splats alongside interactive 3D ribbons, an active 2D radar minimap, and mobile Augmented Reality (AR) HUD navigation. Raasta-3D achieves 60 FPS in standard browsers with zero native installation.

1. Problem Statement & Motivation

Satellite GPS fails indoors due to microwave signal attenuation and multi-path reflection through walls. Visitors entering complex facilities—large retail stores like IKEA, corporate headquarters, or festival arenas like Techfest IIT Bombay—are forced to decipher static floorplans. Existing commercial solutions require LiDAR rigs costing upwards of $15,000. Raasta-3D eliminates these costs by enabling anyone with an ordinary smartphone to create a metric 3D digital twin, search for landmarks or items, and receive optimal, collision-free walking directions that route cleanly around real physical obstacles like walls and furniture.

3. Smartphone Capture Standard Operating Procedure (SOP)

  • Exposure & Focus Locking (AE/AF Lock): Operators tap and hold to lock exposure prior to recording, eliminating photometric inconsistencies.
  • Kinematic Trajectory (Two-Pass Concentric Loop):
    • Pass 1 (Perimeter Structural Loop): Walking the outer perimeter facing forward at 0° horizontal at an even gait (0.3 - 0.5 m/s) with ≥ 75% visual overlap.
    • Pass 2 (Inward Landmark Sweep): Tracing an inner path pitched 25°-35° inward to capture full volumetric parallax of central obstacles.
  • Global Loop Closure: Recording terminates at the exact starting point to enable bundle adjustment to eliminate metric scale drift.

4. 3D Gaussian Splatting & Physical Obstacle Avoidance

Scenes are represented via explicit 3D Gaussians parameterizing position $\boldsymbol{\mu}$, opacity $\alpha$, and covariance $\boldsymbol{\Sigma} = \boldsymbol{R} \boldsymbol{S} \boldsymbol{S}^T \boldsymbol{R}^T$. Color is encoded via spherical harmonics (SH) coefficients. During rasterization, Gaussians are transformed into 2D camera coordinates and sorted by depth, achieving tile-based rendering at 60 FPS directly within WebGL.

Navigation paths cannot simply cut diagonally through obstacles: they must strictly stay on the floor and route around physical obstructions (walls, kitchen islands, beds, sofas). We construct a topological navmesh graph where each node represents a collision-free corridor midpoint, doorway threshold, or POI location.

1. Quickstart Instructions for Evaluators

  1. Open https://raasta-3d.vercel.app in Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari.
  2. Click "Walk" on the top navbar, then click the 3D canvas to lock mouse pointer look.
  3. Use W / A / S / D to walk, Shift to sprint, and C to crouch. Observe that continuous collision detection stops your avatar from clipping through walls or furniture.
  4. Click directly on any room floor (Living Room, Kitchen, Bedroom, Study) to reveal designated names, square footages, and key amenities.
  5. Press Ctrl + K to search for specific objects or POIs.
  6. Click "Navigate Here" on any POI card. An animated glowing cyan ribbon appears on the floor, routing cleanly around obstacles to your target.
  7. Click "Roam to Target" in the top Navigation HUD. The camera auto-walks smoothly along the path all the way to your destination.

1. Local Setup Instructions

# 1. Clone the repository
git clone https://github.com/Sarthakadhav/Raasta-3D.git
cd Raasta-3D

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev

# 4. Production build & preview
npm run build
npm run preview

2. 100% Free Google Colab Pipeline

  1. Open pipeline/Namma_Space_Raasta3D_Pipeline.ipynb in Google Colab.
  2. Select Runtime > Change runtime type > Hardware accelerator > T4 GPU (100% free).
  3. Upload your smartphone video (indoor_capture.mp4).
  4. Run all cells: ns-process-data video, ns-train splatfacto, ns-export gaussian-splat.
  5. Download the exported .splat file and drag it into the web viewer.
